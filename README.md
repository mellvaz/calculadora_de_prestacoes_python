# 💰 Calculadora de Prestações e Relatório Diário em Python

Este projeto consiste numa solução em Python para o cálculo de pagamentos de prestações com aplicação de juros/multas por atraso, além da geração de um relatório diário de encerramento.

Desenvolvido para praticar a criação de **funções**, estruturas de repetição **`while`** e acúmulo de dados em variáveis.

---
## 📌 Funcionalidades

* **Cálculo Automático de Juros:**
  * Sem atraso: cobra apenas o valor original da prestação.
  * Com atraso: aplica **3% de multa** + **0,1% de juros por dia** de atraso sobre o valor da prestação.
* **Leitura Contínua:** Permite calcular múltiplos pagamentos em sequência.
* **Relatório do Dia:** Ao digitar `0` no valor da prestação, o programa encerra a execução e exibe:
  * A quantidade total de prestações pagas no dia.
  * O valor total acumulado arrecadado no dia.
